## 📌 Project Overview
The objective of this project is to analyze customer participation in an Airlines Loyalty Program, identify high-value customer segments based on their flight activity and salary levels, and track booking trends across different cities and loyalty card tiers.

---

## 🛠️ Data Processing & Workflow

1. **Data Cleaning & Preprocessing (Excel & AI Tools):**
   - Cleaned raw airlines data using Excel and AI-assisted functions.
   - Handled missing values, formatted columns (salaries, flight counts, distances), and standardizing categorical labels.

2. **Data Transformation (Power Query):**
   - Imported cleaned dataset into Power BI Desktop.
   - Performed data type corrections, applied custom column transformations, and filtered anomalies in Power Query.

3. **Data Modeling & Visualization (Power BI):**
   - Created DAX measures for aggregated metrics (Total Flights, Distance, Loyalty Counts).
   - Designed an interactive single-page dashboard with custom KPI cards, gauge visual, trend line chart, donut distribution, and bar charts.

---

## 📊 Key Dashboard Insights

- **Loyalty Tier Distribution:** **Star Tier** holds the largest share (~48.5%) of loyalty card holders, followed by **Nova** (~31.8%) and **Aurora** (~19.7%).
- **Booking Trends:** Monthly flight bookings show a clear seasonal surge, peaking around mid-year (Months 6–8) before tapering off toward year-end.
- **Salary vs. Flights Analysis:** Provides insights into the relationship between customer compensation/salary brackets and average flight frequencies.
- **Geographic Slicing:** Interactive city-level slicer allowing dynamic drill-downs for specific locations (e.g., Ottawa, St. John's, Montreal).
